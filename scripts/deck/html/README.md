# HTML-колода: движок и слоты

Два веб-компонента для колод, собираемых как обычный HTML: `deck-stage.js` —
сцена со слайдами, `image-slot.js` — заполняемый пользователем слот под картинку.
Подробное описание API и атрибутов — в шапке каждого файла.

Соседний `../SKILL.md` — про другое: профилирование и линт готовых `.pptx`.
Здесь HTML-колода, которую верстают руками и печатают в PDF.

## Подключение

Компоненты кладутся рядом с `index.html` или линкуются на этот каталог, чтобы
правка движка доходила до всех колод сразу:

```bash
ln -s ../research-stack/scripts/deck/html/deck-stage.js deck-stage.js
ln -s ../research-stack/scripts/deck/html/image-slot.js image-slot.js
```

Один `<section>` — один слайд, содержимое статический HTML. Сцена масштабирует
холст фиксированного размера (по умолчанию 1920×1080) через `transform: scale()`,
letterbox по краям. Атрибут `noscale` отключает масштабирование — его ставит
экспортёр в pptx, которому нужна неискажённая геометрия. Печать разложена через
`@media print`: браузерное «Печать → Сохранить как PDF» даёт по странице на слайд
без дополнительной настройки.

## Три ловушки, которые стоили времени

**Входные анимации гейтить `[data-deck-active]`** и `@media (prefers-reduced-motion:
no-preference)`, базовое состояние делать видимым (`opacity: 1`). Иначе скриншот в
момент загрузки поймает `opacity: 0` — и это артефакт захвата, а не поломка вёрстки.
Проверять надо осевшее состояние, отключив анимацию: `el.style.animation = 'none'`.

**Короткие имена CSS-классов уже заняты глобально** — `.lg`, `.ml`, `.n`, `.s`, `.tl`
и подобные. Новый блок получает уникальный префикс (`.lgi`, `.bgraph .bn`), иначе
чужое правило молча обрежет вёрстку.

**Кириллица в имени файла ломает часть инструментов** (batch-замены жалуются на
недопустимые символы). Обходной путь — скопировать в ASCII-имя, прогнать замену,
скопировать обратно. Длинное тире в именах не использовать вовсе, только дефис.

## Слот под изображение

Реальные картинки в проект обычно не скачиваются: вместо этого ставится
`<image-slot>` с точной подписью-инструкцией и ссылкой на источник — пользователь
перетаскивает файл сам. Заполненный слот переживает перезагрузку через sidecar
`.image-slots.state.json` рядом с HTML, поэтому картинка видна и по ссылке, и в
скачанном архиве, и в экспорте. Вне runtime слот работает только на чтение.

Хост-мост разрешает запись sidecar лишь в корне проекта — значит, использующий
компонент HTML тоже лежит в корне.

## Иллюстрации на всю панель

Грязные иллюстрации должны заполнять панель целиком, иначе сверху и снизу остаются
дыры: `.pane-art { align-items: stretch; justify-content: flex-start }` плюс
`flex: 1` на корневом элементе арта.
